# Auto Reminder v2
Българско Android приложение за няколко автомобила.

Функции:
- няколко автомобила;
- текущ километраж;
- напомняния за ГО, ГТП, винетка, масло, гуми и други обслужвания;
- дата и целеви километраж;
- планирани интервали;
- GitHub Actions за онлайн build на APK.

## Онлайн build
Качи съдържанието в GitHub repository и отвори **Actions → Build APK → Run workflow**. След успешен build APK се намира в Artifacts.
